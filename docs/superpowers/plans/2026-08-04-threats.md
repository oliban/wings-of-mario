# Threats to the Plane — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The sky stops being safe. Today the pilot can only die by flying into terrain, into the sea, into the ship, or into his own blast — every one of them his own mistake. After this plan the *level* shoots back, and so does *Mario*. Spec §5's four layers all land: repurposed Mario enemies as anti-aircraft, Mario's own fire flower and star, terrain (already built), and neutral naval flak.

**Architecture:** Split authority (spec §7.1). The plane belongs to the pilot's client, so **the plane's hitbox is evaluated on exactly one machine: the pilot's.** That single sentence decides every question in this plan and is argued in full below. Anti-aircraft fire is *derived* from static level data rather than read out of Mario's running engine, which is what lets an island Mario has never visited still defend itself (spec §4.3). Mario's counterplay reaches the pilot as three extra fields on a snapshot he is already sending.

**Tech Stack:** Vanilla ES modules in `src/`, no build step, no npm dependencies in `src/`, no TypeScript. Node's built-in `node:test` for tiers 1–2, Playwright (already a devDependency) for tier 3.

**Ordering rule that governs this plan:** Task 3 ends with **a pilot who gets shot down flying low over 8-3**, in a real browser, with no server and no second player. Tasks 1 and 2 are the smallest pure core that makes that real. Tasks 4–6 each add a threat on top of something already playable. Nothing here is scaffolding.

**Engine footprint: zero.** `MODS.md` records 150 lines across three files (`src/game/world.js`, `src/main.js`, `index.html`) and this plan does not add a line to any of them. Everything below lives in `src/wings/`, `src/net/` and `tests/`, which upstream has never heard of. Task 6 is the only task that even touches a file outside `src/wings/` — two of them, both in `src/net/`.

## Global Constraints

Copied from the spec and from `ARCHITECTURE.md`, which remains binding. Every task's requirements implicitly include this section.

- **No build step. No npm dependencies in `src/`. No TypeScript.** Every file under `src/` is a `.js` ES module loaded natively by the browser.
- **Zero engine edits.** Nothing under `src/core`, `src/game`, `src/render`, `src/data`, `src/ui`, `src/audio`, and not `src/main.js` or `index.html`. `git status --porcelain` over those paths must print nothing when this plan is done. If a task ever appears to need engine surface, stop and re-read Task 1 — the reason this plan does not need any is that it reads level *data*, which is already imported freely by `src/wings/archipelago.js` and `src/wings/island.js`.
- **Coordinate system:** origin top-left, +X right, **+Y DOWN**. `TILE = 16`. Positions are floating-point pixels; velocities are pixels **per frame**, not per second.
- **The 320-pixel seam.** `ISLAND_TOP_Y = 320`, `SEA_Y = 560`, `CEILING_Y = 0`. Level data — `level.tiles`, `level.entities` — is in **island-local tiles**. The plane, its shots and every flak round in this plan are in **world pixels**. `flak.js` is the one module that crosses the seam, it crosses it once, in `emplacementAt()`, and every other module in this plan is world-space throughout. `geo.js` exports `assertLocalY(y, label)`; Task 1 uses it on the local side of that one conversion.
- **Fixed timestep:** `FPS = 60.0988`, `DT = 1 / FPS`. **Simulation code must never read wall-clock time (`Date.now`, `performance.now`) or unseeded randomness.** Every module added here takes its entropy from `new Rng(seed)` (`src/core/rng.js`) with a seed derived from the match seed, and holds no module-level mutable state.
- **What "deterministic" means for anti-aircraft fire**, precisely, because this plan makes a claim narrower than the one Plan 4's archipelago makes: the same match seed plus the same *input tape* gives the same match (spec §8.1). AA aims at the aeroplane, so its rounds are a function of the pilot's flying — they are reproducible from a replay, not computable independently on Mario's machine. That is sound because **Mario's machine never needs them**: nothing on his side reads, draws or resolves a flak round. See "Deliberately not in this plan".
- **Tile keys are the string `` `${tx},${ty}` ``**, island-local, produced by `tileKey(tx, ty)` from `src/wings/blast.js`. Suppression in Task 1 reads `island.destroyed`, which holds exactly these.
- **Island ids are level ids** — `'1-1'`, `'8-3'`.
- **Never use ports 8123, 4322 or 8199 in any command.** The browser task reuses `boot()` from `tests/browser/helpers.mjs`, which spawns its own server; no port number is typed into any command in this plan.
- **Original assets only.** No Nintendo ROM art or audio. Anti-aliasing is forbidden; hard pixel edges only.
- **Commit after every task.** Do not push to any remote; the user pushes.

## The ruling: where a hit on the plane is decided

Spec §7.3 settles two of the three cases by name and leaves the third to this plan.

> - **Bomb hits Mario?** Mario's client decides.
> - **Mario's fireball hits the plane?** The pilot's client decides.

The unanswered one is the one this plan is mostly made of: **an enemy's projectile against the plane.** The enemies live in Mario's simulation; the plane lives in the pilot's.

**Ruling: the pilot's client decides, and it decides against rounds it fired itself.**

Generalised, so that no future task has to re-derive it:

> **The plane's hitbox is evaluated on exactly one machine — the pilot's. Nothing on Mario's client ever runs a test whose answer is "the plane was hit."**

That is the mirror image of the rule already implemented in `src/net/mario-side.js`, whose `onDamage()` carries the comment *"THE HIT RESOLUTION, and the reason this method is on Mario's side of the wire and not the pilot's."* Between them the two rules cover every hit in the game with no overlap and no gap: **Mario's client owns Mario's hitbox; the pilot's client owns the plane's.**

### What follows from it, in three parts

**1. Anti-aircraft fire never crosses the wire at all.** If the pilot decides the hit, and the pilot can compute where the guns are, then there is no reason for a round to be a network object. So AA emplacements are **derived from static level data** — `level.entities` for Piranha Plants, Hammer Bros and Bowser, a `'K'` tile scan for Bullet Bill cannons — and the pilot's sim fires them locally at 60Hz. Zero bytes, zero latency, zero acks, and no new reliable event type.

**2. This is what makes an unvisited island dangerous.** Spec §4.3: *"No inactive island is ever simulated. An island Mario is not on is just a level definition plus its destroyed-set."* If AA were the engine's real `Piranha` and `HammerBro` objects, an island Mario is not standing on would have no guns on it, and pre-bombing island 4 — the strategy the archipelago exists for — would be completely free. Deriving from level data means island 4 defends itself from the first minute of the match, and it costs the same nothing that Plan 4's islands cost.

**3. Suppression becomes a real mechanic for free.** An emplacement is derived from a tile, and `Island#destroyed` is already synchronised across both clients by Plan 3's damage map. Crater the tile, silence the gun — **permanently, for the match**, exactly like the terrain it sits on. That is the risk/reward loop this whole plan is tuned around, and it required no new state.

### The cases against it, answered

- *"Mario's client owns his enemies, so it should own their bullets."* It owns the enemies **it is simulating**, which is one island's worth, only while he is standing on it. AA has to exist on four islands at once. These are not the same population and pretending they are is what makes the rule break down.
- *"The pilot can cheat by ignoring flak."* Yes. Spec §7.1: *"Optimised for feel over anti-cheat; this is a game friends play together."* The same trade already lets Mario's client ignore a bomb.
- *"Then a round should at least be sent so Mario can see it."* He is 320 pixels below and looking the other way. Spec §4.2 gives telegraphing to Mario, for **bombs**, because a crater is permanent and his counterplay is not being there. A flak round threatens nothing of his. See "Deliberately not in this plan".
- *"Mario's fireball is his object, so he should decide."* Spec §7.3 says otherwise, in one line, and the reason is latency: Mario's client sees the plane through `INTEGRATE_DELAY_TICKS = 6` ticks of interpolation delay (`src/net/protocol.js` exports `INTERP_DELAY_TICKS = 6`), so a hit decided there is decided against a plane that has since moved up to 27 pixels. The pilot's plane is real-time and exact.

### What Mario sends, then

Only **facts about himself**, which he already sends 20 times a second. Task 5 adds three: his live fireballs, whether he is starred, and (already present) his `vy`. The pilot converts them into world space and runs the test. No new message type, no ack, no protocol version bump — `validate()` for `MSG.SNAP` is deliberately shape-only (*"the contents of `s` are not this layer's business"*), so the snapshot body extends without touching `src/net/protocol.js`.

### Where a kill lands

Everything that destroys the plane funnels into `WingsSim#lose(reason)`, which already decrements `sim.squadron` and emits `planeLost`. `src/net/pilot-side.js` already turns that into the reliable `planeLost` wire event through `pilotWireEvent`, and Plan 4's `Match#planeLost()` already ends the match at zero. **This plan adds no match plumbing whatsoever** — it adds new values of `reason`.

## Task 1: Where the guns are

The level's own defences, read out of the level definition. No firing, no rounds, no canvas, no sim — just: given an `Island`, which guns does it have, where are their muzzles in **world** pixels, how far can each one reach, and which of them has been bombed silent.

This is the only module in the plan that touches island-local coordinates, and it touches them in exactly one function.

**Files:**
- Create: `src/wings/flak.js`
- Create: `tests/unit/flak.test.js`

**Interfaces produced:**
- `flak.js` — `AA`, `EMPLACEMENT`, `KINDS`, `emplacementId(islandId, kind, tx, ty)`, `emplacementAt(island, kind, txf, ty)`, `cannonTiles(island)`, `entityEmplacements(island)`, `derivedEmplacements(island)`, `suppressed(island, e)`, `liveEmplacements(island)`, `inReach(e, px, py)`

### The intended risk/reward

The reach numbers below are the whole balance of Task 3, so they are stated before the code rather than discovered from it.

Emplacement muzzles sit on the island's own terrain, which in these levels means rows 7–12 — world y **432 to 512**. The island's top edge is y **320** and the altitude ceiling is y **0**. So "how high does a gun reach" is really "how far above the island top is the pilot safe".

| Kind | Reach (px above muzzle) | Arc (px either side) | Threatens |
|---|---|---|---|
| `plant` (Piranha) | 160 | 64 | A pass **at or below the island's own skyline**. Almost a terrain hazard: if a plant can touch you, so can a hilltop. |
| `bro` (Hammer Bro) | 240 | 176 | The **bombing altitude**. This is the gun the pilot actually has to think about, and the one the census puts on the world-3-and-up islands. |
| `cannon` (Bullet Bill) | 360 | 208 | A comfortable working altitude, straight and fast. Rare (five levels ship them) and correspondingly nasty. |
| `bowser` | 200 | 256 | A wide, low fire wall across a castle. Short-reaching, but the only round that costs **two** points of integrity. |
| `flak` (naval, Task 4) | 520 | 360 | Everything, including the top of the band. The answer to "just fly high". |

Read down the "threatens" column and the loop falls out: **the pilot cannot bomb accurately and stay safe at the same time.** Bombs are ballistic and inherit plane velocity, so a high release scatters; a low release is precise and puts him inside `bro` and `cannon` reach. His way out is not better flying, it is **suppression** — crater the emplacement tile on a fast high pass, and that gun is gone for the rest of the match, because craters are permanent (spec §4.1). That is the risk/reward an implementer tuning these numbers is tuning toward: *the first pass over a defended island should be about the guns, and the second should be about the ground.*

```js
import { TILE } from '../core/constants.js';
import { ISLAND_TOP_Y, assertLocalY } from './geo.js';
import { tileKey } from './blast.js';

// WHERE THE GUNS ARE.
//
// The level defends itself. Every emplacement in here is DERIVED from the
// level definition an Island already holds — the tile map for Bullet Bill
// cannons, `level.entities` for Piranha Plants, Hammer Bros and Bowser — and
// never from Mario's running engine.
//
// That is not a shortcut, it is the point. Spec 4.3: an island Mario is not
// standing on is never simulated, it is a level definition plus a
// destroyed-set. If the guns were the engine's real entities, three of the
// four islands in a world would be undefended at any moment and pre-bombing
// island 4 — the strategy the archipelago exists for — would be free. Derived
// from data, island 4 has been dangerous since the match started, and it cost
// nothing to make it so.
//
// PURE AND DETERMINISTIC: no clock, no randomness, no canvas, no engine
// import that reaches a running World. The only mutable thing consulted is
// the island's own `destroyed` set, which Plan 3 keeps byte-identical on both
// clients.
//
// COORDINATES. Level data is island-LOCAL tiles. Everything this module hands
// out is WORLD pixels. emplacementAt() is the single crossing point, and the
// only place in this plan where ISLAND_TOP_Y appears.

export const EMPLACEMENT = {
  CANNON: 'cannon',
  PLANT: 'plant',
  BRO: 'bro',
  BOWSER: 'bowser',
};

// The balance table. REACH is how far ABOVE the muzzle a gun can hit, ARC is
// how far to either side, both in world pixels. CADENCE is ticks between
// salvos before jitter. See the plan's risk/reward table: these are ordered so
// that the bombing altitude is contested, the skyline is lethal, and the top
// of the band belongs to naval flak alone.
//
// Reference points, because a bare number is untunable: the island band runs
// y 320 (top) to 560 (sea). Muzzles sit on terrain, rows 7-12, so y 432-512.
// An aeroplane bombing accurately is at roughly y 250-300.
export const AA = {
  [EMPLACEMENT.PLANT]: { REACH: 160, ARC: 64, CADENCE: 90, DAMAGE: 1, ROUND: 'spit' },
  [EMPLACEMENT.BRO]: { REACH: 240, ARC: 176, CADENCE: 120, DAMAGE: 1, ROUND: 'hammer' },
  [EMPLACEMENT.CANNON]: { REACH: 360, ARC: 208, CADENCE: 150, DAMAGE: 1, ROUND: 'bill' },
  [EMPLACEMENT.BOWSER]: { REACH: 200, ARC: 256, CADENCE: 200, DAMAGE: 2, ROUND: 'breath' },
};

export const KINDS = Object.keys(AA);

// Which `level.entities` types are anti-aircraft, and which are just enemies.
// A goomba cannot reach an aeroplane and a firebar is nailed to a castle wall.
const ENTITY_KIND = {
  piranha: EMPLACEMENT.PLANT,
  hammerbro: EMPLACEMENT.BRO,
  bowser: EMPLACEMENT.BOWSER,
};

// The cannon barrel character in the tile legend (src/data/tiles.js: 'K' is
// cannon-barrel, id 25; 'k' is cannon-base, id 26). Only the barrel shoots.
const CANNON_CHAR = 'K';

// Stable across rebuilt Islands and across a sail. Archipelago#islands()
// constructs fresh Island objects whenever the ocean changes, so an identity
// held on the object would reset every gun's cadence each time the carrier
// group weighed anchor. The id is a function of the level, not of the run.
export function emplacementId(islandId, kind, tx, ty) {
  return `${islandId}:${kind}:${tx},${ty}`;
}

// THE ONE SEAM CROSSING. `txf` may be fractional — a Piranha entity's x is a
// half tile, because the plant straddles the two columns of its pipe — so the
// muzzle is computed from the float and the TILE the emplacement occupies is
// derived from it afterwards, never the other way round.
export function emplacementAt(island, kind, txf, ty) {
  const spec = AA[kind];
  if (!spec) throw new Error(`flak: unknown emplacement kind "${kind}"`);
  // Island-local, and asserted as such: a world y here would silently place
  // every gun in the world 320px into the seabed.
  assertLocalY(ty * TILE, `flak ${kind} ty`);
  const tx = Math.floor(txf + 0.5);
  return {
    id: emplacementId(island.id, kind, tx, ty),
    island: island.id,
    kind,
    tx,
    ty,
    // World pixels from here down. x is the centre of the emplacement's body,
    // y is the TOP of its own tile: every gun here fires upward out of the
    // thing it is sitting in.
    x: island.originX + (txf + 0.5) * TILE,
    y: ISLAND_TOP_Y + ty * TILE,
    reach: spec.REACH,
    arc: spec.ARC,
    cadence: spec.CADENCE,
    damage: spec.DAMAGE,
    round: spec.ROUND,
  };
}

// Cannons are TILES, not entities — see the header of
// src/game/entities/cannons.js, which explains that the original files them
// into a six-entry ring as the level scrolls. We want all of them, always:
// the pilot can be over any part of the island at any time and there is no
// "scrolled onto" for him.
export function cannonTiles(island) {
  const out = [];
  for (let ty = 0; ty < island.h; ty++) {
    const row = island.rows[ty];
    for (let tx = 0; tx < row.length; tx++) {
      if (row[tx] === CANNON_CHAR) out.push({ tx, ty });
    }
  }
  return out;
}

// Read the raw rows, NOT island.charAt(): charAt already returns '.' for a
// destroyed tile, and an emplacement that stops EXISTING when bombed cannot
// be told apart from one that was never there. Existence comes from the level;
// suppression is a separate question, asked below.
export function entityEmplacements(island) {
  const list = (island.level && island.level.entities) || [];
  const out = [];
  for (const e of list) {
    const kind = ENTITY_KIND[e && e.type];
    if (!kind) continue;
    out.push(emplacementAt(island, kind, e.x, e.y));
  }
  return out;
}

// Every gun on the island, live or silenced, in a stable sorted order. The
// order is load-bearing: Task 2 seeds each emplacement's cadence from its id,
// but a caller iterating the list must see the same list twice in a row or a
// salvo can be attributed to the wrong gun.
export function derivedEmplacements(island) {
  const out = [];
  for (const { tx, ty } of cannonTiles(island)) {
    out.push(emplacementAt(island, EMPLACEMENT.CANNON, tx, ty));
  }
  for (const e of entityEmplacements(island)) out.push(e);
  out.sort((a, b) => (a.id < b.id ? -1 : a.id > b.id ? 1 : 0));
  return out;
}

// SUPPRESSION, and the reason this whole plan needed no new shared state.
//
// A gun is silenced when its own tile is destroyed, or when the tile directly
// under it is. Both cases are real: a bomb through the barrel kills a cannon
// or a pipe, and a bomb through the floor takes away the thing a Hammer Bro
// or Bowser was standing on. Checked against the census, every emplacement in
// every shipped level has a non-air tile in at least one of those two places,
// so no gun is unkillable.
//
// `island.destroyed` is Plan 3's replica of the server's per-island set, so
// both clients agree on which guns are dead without a byte of new protocol —
// and because craters are permanent for the match (spec 4.1), so is this.
export function suppressed(island, e) {
  return island.destroyed.has(tileKey(e.tx, e.ty))
    || island.destroyed.has(tileKey(e.tx, e.ty + 1));
}

export function liveEmplacements(island) {
  return derivedEmplacements(island).filter((e) => !suppressed(island, e));
}

// Is a point inside this gun's envelope? Reach is measured strictly UPWARD
// (smaller y) from the muzzle — +Y is down — so a target level with the muzzle
// or below it is not a target, it is the ground.
export function inReach(e, px, py) {
  const up = e.y - py;
  if (up <= 0 || up > e.reach) return false;
  return Math.abs(px - e.x) <= e.arc;
}

export default { AA, EMPLACEMENT, KINDS, derivedEmplacements, liveEmplacements };
```

## Task 2: The guns fire

Cadence, aim, round physics and the hit predicate. Still no sim, no canvas and no wire — a `Battery` is handed a list of `Island`s and a plane-shaped object and produces rounds and hit events.

The rounds ride **`ordnance.js`'s own integrator**. That module's `stepShot` currently looks its spec up in the `ORDNANCE` table by kind, which would mean either putting flak into the pilot's ammunition table (where `createLoadout()` would issue him a magazine of Bullet Bills) or writing a second copy of `vy += g; x += vx; y += vy; age++`. Neither is acceptable, so `stepShot` gains a **defaulted second parameter**. Every existing call site passes one argument and is unaffected.

**Files:**
- Modify: `src/wings/ordnance.js`
- Create: `src/wings/battery.js`
- Create: `tests/unit/battery.test.js`

**Interfaces produced:**
- `ordnance.js` — `stepShot(s, spec = ORDNANCE[s.kind])` (signature change only; behaviour with one argument is identical)
- `battery.js` — `AA_ROUNDS`, `BATTERY`, `salvoSeed(seed, id, salvo)`, `jitteredCadence(rng, cadence)`, `aimAt(e, spec, target)`, `planeBox(plane)`, `segmentHitsBox(x0, y0, x1, y1, box, pad)`, `hitsPlane(round, fromX, fromY, plane)`, `class Battery`

### The intended risk/reward

Round speeds are set against the aeroplane's, which is the only number that matters here: `FLIGHT.MAX_SPEED` is 4.5 px/frame and a comfortable cruise is 2.69.

- **Nothing outruns a `bill` (4.2) in a straight line**, but every gun leads a *predicted* position, so a pilot who changes heading after the muzzle flash makes the round miss. That is the skill this system asks for, and it is the same skill the pilot is asking of Mario when he leads a bomb by eye (spec §4.2).
- **Nothing is instant.** The slowest round (`breath`, 2.6) takes over a second to cross Bowser's arc, so a fire wall is something you fly around, not something that happens to you.
- **A gun leads, it does not track.** No round steers after launch. Once it is in the air it is geometry.
- **Twenty-four rounds in the air, hard cap.** 6-2 ships twenty-eight Piranha Plants; without a cap, one island would be a solid wall of spit and the pilot's only counterplay would be never to go there. The cap makes a dense island *sustainedly* dangerous rather than *instantly* fatal, which is the difference between a threat and a wall.

```js
// Pure physics: gravity and motion only. This module has no idea what
// terrain or sea level look like — that is world/engine knowledge — so a
// shot only dies here of old age. The caller decides when a shot has hit
// something (island tile query, sea level, whatever) and calls detonate().
//
// `spec` defaults to the ORDNANCE entry for the shot's kind, which is every
// call in the pilot's own code. It is a parameter at all so that anti-aircraft
// fire (src/wings/battery.js) can ride this exact integrator without its
// rounds being entries in ORDNANCE — which is the pilot's AMMUNITION table,
// and createLoadout() would otherwise issue him a magazine of Bullet Bills.
export function stepShot(s, spec = ORDNANCE[s.kind]) {
  s.vy += spec.gravity;
  s.x += s.vx;
  s.y += s.vy;
  s.age++;
  if (s.age >= spec.life) s.dead = true;
  return s;
}
```

- [ ] **Step 4: Write the battery**

Create `src/wings/battery.js`:

```js
import { Rng } from '../core/rng.js';
import { SEA_Y, PLANE_W, PLANE_H } from './geo.js';
import { MODE } from './flight.js';
import { stepShot } from './ordnance.js';
import { AA, EMPLACEMENT, liveEmplacements, suppressed, inReach } from './flak.js';

// THE GUNS FIRING.
//
// Everything an emplacement does between "it exists" (flak.js) and "the plane
// took a hit" (sim.js). Pure and seeded, in WORLD pixels throughout: nothing
// in this file knows what an island-local coordinate is.
//
// WHOSE MACHINE THIS RUNS ON: the pilot's, and only the pilot's. See the
// ruling at the top of the plan this was built from — the plane's hitbox is
// evaluated on exactly one machine, so a flak round never becomes a network
// object, is never acked, and costs nothing to have in flight over an island
// nobody is standing on.
//
// The rounds use ordnance.js's own stepShot with their own spec table, so
// there is exactly one ballistic integrator in this codebase.

// px/frame, like every other velocity in the game. `speed` is muzzle speed,
// `gravity` is added to vy each tick, `life` is in ticks, `radius` pads the
// plane's box in the hit test.
//
// Calibrated against the aeroplane: FLIGHT.MAX_SPEED is 4.5 and a cruise is
// 2.69. Nothing here outruns a plane in a straight line by much, and every
// gun leads a PREDICTED position, so changing heading after the muzzle flash
// is the counterplay.
export const AA_ROUNDS = {
  spit: { speed: 3.0, gravity: 0.05, life: 100, radius: 4 },
  hammer: { speed: 3.4, gravity: 0.06, life: 160, radius: 5 },
  bill: { speed: 4.2, gravity: 0, life: 130, radius: 7 },
  breath: { speed: 2.6, gravity: 0, life: 110, radius: 6 },
};

export const BATTERY = {
  // Cadence is multiplied by 1 +/- this. Guns on one island must not volley
  // together, and a gun must not become a metronome the pilot can count.
  JITTER: 0.25,
  // How many rounds may be in the air at once, across the whole ocean. 6-2
  // ships twenty-eight Piranha Plants; uncapped, that island is a wall rather
  // than a threat, and a wall has no counterplay but avoidance.
  MAX_ROUNDS: 24,
  // A round is dropped once it is this far past the sea or above the ceiling.
  SEA_MARGIN: 8,
  SKY_MARGIN: 128,
};

// A distinct, stable stream per gun per salvo — the same trick radar.js uses
// per sweep. Mixing the gun id in is what stops an island firing in lockstep;
// mixing the salvo index in is what stops one gun becoming a metronome.
export function salvoSeed(seed, id, salvo) {
  let h = (seed >>> 0) ^ 0x9e3779b1;
  for (let i = 0; i < id.length; i++) {
    h = Math.imul(h ^ id.charCodeAt(i), 0x01000193) >>> 0;
  }
  h = (Math.imul(h ^ 0x85ebca6b, 0x27d4eb2d) ^ Math.imul(salvo + 1, 0x9e3779b1)) >>> 0;
  return h || 0x2545f491;
}

export function jitteredCadence(rng, cadence) {
  return Math.round(cadence * rng.range(1 - BATTERY.JITTER, 1 + BATTERY.JITTER));
}

// Lead the target. Two refinement passes: guess the flight time from the
// current distance, move the target along its own velocity by that much, and
// re-time against the new point. Two is enough at these speeds and, unlike a
// closed-form intercept solve, it degrades into "shoot at where he is" rather
// than into a square root of a negative number when the target is faster than
// the round — which a diving aeroplane routinely is.
//
// For a lobbed round the muzzle is then tilted up by half the gravity the
// round will accumulate over its flight, which is the exact correction that
// puts a constant-acceleration projectile back on the straight-line point.
export function aimAt(e, spec, target) {
  let tx = target.x;
  let ty = target.y;
  for (let i = 0; i < 2; i++) {
    const t = Math.hypot(tx - e.x, ty - e.y) / spec.speed;
    tx = target.x + (target.vx || 0) * t;
    ty = target.y + (target.vy || 0) * t;
  }
  const dx = tx - e.x;
  const dy = ty - e.y;
  const d = Math.hypot(dx, dy) || 1;
  const flight = d / spec.speed;
  return {
    vx: (dx / d) * spec.speed,
    vy: (dy / d) * spec.speed - (spec.gravity * flight) / 2,
  };
}

// x,y is the plane's TOP-LEFT (ARCHITECTURE.md section 1), not its centre.
export function planeBox(plane) {
  return { x: plane.x, y: plane.y, w: PLANE_W, h: PLANE_H };
}

// Segment against an axis-aligned box grown by `pad`, by the slab method.
// Exact, not sampled: a round moving 30px in a tick past a 12px-tall aeroplane
// must not be able to step over it, and sub-sampling only makes that unlikely.
export function segmentHitsBox(x0, y0, x1, y1, box, pad = 0) {
  const minX = box.x - pad;
  const minY = box.y - pad;
  const maxX = box.x + box.w + pad;
  const maxY = box.y + box.h + pad;
  const dx = x1 - x0;
  const dy = y1 - y0;
  let t0 = 0;
  let t1 = 1;
  for (const [p, lo, hi, o] of [[dx, minX, maxX, x0], [dy, minY, maxY, y0]]) {
    if (Math.abs(p) < 1e-12) {
      // Parallel to this slab: either inside it for the whole segment or never.
      if (o < lo || o > hi) return false;
      continue;
    }
    let a = (lo - o) / p;
    let b = (hi - o) / p;
    if (a > b) [a, b] = [b, a];
    if (a > t0) t0 = a;
    if (b < t1) t1 = b;
    if (t0 > t1) return false;
  }
  return true;
}

export function hitsPlane(round, fromX, fromY, plane) {
  return segmentHitsBox(fromX, fromY, round.x, round.y, planeBox(plane), round.radius || 0);
}

export class Battery {
  constructor(opts = {}) {
    this.seed = (opts.seed >>> 0) || 0x2545f491;
    this.tick = 0;
    this.rounds = [];
    this.events = [];
    // Per-gun state, keyed by the stable emplacement id from flak.js so that a
    // rebuilt Island (Archipelago#islands() makes fresh ones on every sail)
    // does not reset every cadence in the world.
    this.cool = new Map(); // id -> ticks remaining
    this.salvo = new Map(); // id -> how many times it has fired
    this.isles = new Map(); // island id -> Island, for the live suppression check
    this.guns = [];
    this._nextId = 1;
  }

  // Point the battery at an ocean. Called once at construction and again on
  // every sail; the previous world's rounds are left behind with it, exactly
  // as WingsSim#sail() drops sim.shots.
  reload(islands = []) {
    this.isles = new Map();
    this.guns = [];
    for (const isle of islands) {
      if (!isle) continue;
      this.isles.set(isle.id, isle);
      // Suppression is re-checked at fire time, so this list is built ONCE per
      // ocean and never rescanned: scanning four full tile maps for 'K' every
      // tick is roughly twenty thousand character reads a frame for nothing.
      for (const e of liveEmplacements(isle)) this.guns.push(e);
    }
    this.rounds = [];
    this.cool = new Map();
    this.salvo = new Map();
    return this;
  }

  emit(type, data) {
    this.events.push({ tick: this.tick, type, ...data });
  }

  drain() {
    const out = this.events;
    this.events = [];
    return out;
  }

  // One fixed 60.0988Hz step. `plane` is anything with x, y, vx, vy and mode.
  step(plane) {
    this.tick++;
    const live = !!plane && plane.mode === MODE.AIR;
    if (live) this.fireControl(plane);
    this.stepRounds(plane, live);
    return this;
  }

  // The centre of the aeroplane, which is what a gun aims at. Its x,y is a
  // corner, and aiming at a corner puts every round systematically low-left.
  static centre(plane) {
    return {
      x: plane.x + PLANE_W / 2,
      y: plane.y + PLANE_H / 2,
      vx: plane.vx || 0,
      vy: plane.vy || 0,
    };
  }

  fireControl(plane) {
    const c = Battery.centre(plane);
    for (const g of this.guns) {
      const isle = this.isles.get(g.island);
      // Bombed silent. Checked live rather than at reload, because the whole
      // point of suppression is that it happens mid-match — and because Plan
      // 3's PilotNet#onDamage applies the server's authoritative keys straight
      // onto these same Island objects (applyToIsland), so this reads the same
      // set on both clients.
      if (isle && suppressed(isle, g)) continue;
      if (!inReach(g, c.x, c.y)) continue;

      let cd = this.cool.get(g.id);
      if (cd == null) {
        // First acquisition. Start on a jittered full cadence so that flying
        // over a dense island is a ragged crackle rather than one volley.
        cd = jitteredCadence(new Rng(salvoSeed(this.seed, g.id, 0)), g.cadence);
        this.cool.set(g.id, cd);
        continue;
      }
      // The clock only runs while the gun can see him: a pilot who stays out
      // of the envelope is not quietly winding every gun on the island up.
      cd -= 1;
      if (cd > 0) {
        this.cool.set(g.id, cd);
        continue;
      }
      if (this.rounds.length >= BATTERY.MAX_ROUNDS) {
        // Hold at zero: the moment the sky clears, this gun fires.
        this.cool.set(g.id, 0);
        continue;
      }
      this.fire(g, c);
      const n = (this.salvo.get(g.id) || 0) + 1;
      this.salvo.set(g.id, n);
      this.cool.set(g.id, jitteredCadence(new Rng(salvoSeed(this.seed, g.id, n)), g.cadence));
    }
  }

  fire(g, target) {
    const spec = AA_ROUNDS[g.round];
    const v = aimAt(g, spec, target);
    const r = {
      id: this._nextId++,
      kind: g.round,
      gun: g.id,
      island: g.island,
      emplacement: g.kind,
      x: g.x,
      y: g.y,
      vx: v.vx,
      vy: v.vy,
      age: 0,
      dead: false,
      radius: spec.radius,
      damage: g.damage,
    };
    this.rounds.push(r);
    this.emit('aaFire', {
      gun: g.id, round: r.kind, emplacement: g.kind, x: r.x, y: r.y, id: r.id,
    });
    return r;
  }

  stepRounds(plane, live) {
    if (!this.rounds.length) return;
    for (const r of this.rounds) {
      if (r.dead) continue;
      // Where it was, captured before stepShot mutates it: the SEGMENT is the
      // hit test, not the endpoint. Same reason WingsSim#stepShots keeps one.
      const fromX = r.x;
      const fromY = r.y;
      stepShot(r, AA_ROUNDS[r.kind]);
      if (r.dead) continue; // old age
      if (r.y > SEA_Y + BATTERY.SEA_MARGIN || r.y < -BATTERY.SKY_MARGIN) {
        r.dead = true;
        continue;
      }
      if (live && hitsPlane(r, fromX, fromY, plane)) {
        r.dead = true;
        this.emit('aaHit', {
          gun: r.gun,
          round: r.kind,
          emplacement: r.emplacement,
          damage: r.damage,
          x: r.x,
          y: r.y,
          id: r.id,
        });
      }
    }
    this.rounds = this.rounds.filter((r) => !r.dead);
  }

  // What the renderer draws. A copy, so the scene cannot stir the simulation.
  state() {
    return this.rounds.map((r) => ({
      id: r.id, kind: r.kind, emplacement: r.emplacement, x: r.x, y: r.y, vx: r.vx, vy: r.vy,
    }));
  }

  reset() {
    this.rounds = [];
    this.events = [];
    this.cool = new Map();
    this.salvo = new Map();
    this.tick = 0;
  }
}

export default Battery;
```

### The intended risk/reward

**Three points of airframe integrity, reset on every rearm.** The number is the whole feel of this task and it was chosen against two failure modes:

- **One point** (a hit is a kill) makes a single unlucky Bullet Bill end a sortie the pilot flew perfectly for two minutes. Spec §3.4 already says the squadron is *"sized so that the pilot is punished for reckless low passes without the match ending on a single mistake"* — the same argument applies one level down.
- **Five or more** and flak is weather. The pilot flies through it, takes his hits, and lands.

At three, a careless low pass costs one pip and a warning, a second careless pass costs another, and the third ends the sortie — **and the pilot always had the option to climb out and go home**, because the panel tells him where he stands. That is the shape: *flak is a budget you spend, not a coin you flip.* Bowser's two-point breath is the deliberate exception, and it is the one gun whose reach is short enough that being inside it is unambiguously a choice.

`integrity` resets in `rearm()`, so it is restored by **landing and rearming**, not by time. Going home is the repair mechanic, which is the sortie loop of spec §3.2 doing its job for free.

```js
  // -------------------------------------------------------------------------
  // Anti-aircraft fire
  // -------------------------------------------------------------------------

  // The battery is stepped AFTER checkPlane, so a plane that has just flown
  // into a hillside is already MODE.DOWN and no gun wastes a round on the
  // wreck — and, more importantly, cannot cost a second aeroplane by hitting
  // it on the way to the ground.
  stepFlak() {
    this.battery.step(this.plane);
    for (const e of this.battery.drain()) {
      if (e.type === 'aaFire') {
        this.emit('aaFire', {
          gun: e.gun, round: e.round, emplacement: e.emplacement, x: e.x, y: e.y,
        });
        continue;
      }
      if (e.type === 'aaHit') {
        this.emit('aaHit', {
          gun: e.gun, round: e.round, emplacement: e.emplacement, x: e.x, y: e.y,
        });
        this.takeHit(e.damage, `flak:${e.emplacement}`);
      }
    }
  }

  // Something got through. Returns true when that was the last of the
  // airframe. EVERY way of damaging the aeroplane funnels through here —
  // flak now, Mario's fireball and his boots in Task 6 — so there is one
  // place that knows how much an aeroplane can take, and one place that turns
  // "hit" into the existing lose()/planeLost()/Match#planeLost() chain. This
  // plan adds no match bookkeeping at all; it adds values of `reason`.
  takeHit(damage, reason) {
    if (this.plane.mode !== MODE.AIR) return false;
    this.integrity -= damage;
    if (this.integrity > 0) {
      this.emit('planeHit', { integrity: this.integrity, damage, reason });
      return false;
    }
    this.integrity = 0;
    this.lose(reason);
    return true;
  }
```

```js
import { PANEL, LAND } from './palette.js';
import { EMPLACEMENT } from '../flak.js';

// Anti-aircraft art. Hard pixel edges only, no anti-aliasing, original
// shapes — nothing here is traced from a ROM.
//
// Everything takes SCREEN coordinates: the caller has already subtracted the
// camera. This module has never heard of a world pixel.

const ROUND_ART = {
  spit: { body: '#7ad048', rim: '#2f6b1c', r: 3 },
  hammer: { body: '#d8d8e0', rim: '#5b5b6b', r: 4 },
  bill: { body: '#1c1c22', rim: '#c8c8d4', r: 5 },
  breath: { body: '#ff8a2a', rim: '#ffe066', r: 5 },
};

// A live emplacement, marked so the pilot can see what he has to suppress.
// Deliberately a MARKER and not a portrait: the landmass art below it already
// draws the cannon tile and the pipe, and a second sprite on top would fight
// with it. This is the threat ring, not the object.
export function drawEmplacement(ctx, e, sx, sy, tick) {
  const pulse = (tick % 60) < 30 ? 1 : 0.55;
  const hot = e.kind === EMPLACEMENT.BOWSER;
  ctx.save();
  // The muzzle stub, pointing up out of whatever it is sitting in.
  ctx.fillStyle = hot ? '#c8501c' : '#3a4450';
  ctx.fillRect(Math.round(sx) - 2, Math.round(sy) - 5, 4, 6);
  ctx.fillStyle = hot ? '#ffb03a' : '#8fa2b4';
  ctx.fillRect(Math.round(sx) - 1, Math.round(sy) - 6, 2, 2);
  // A small threat caret above it, so a gun reads as a gun from altitude and
  // not as another rock.
  ctx.globalAlpha = pulse;
  ctx.fillStyle = hot ? PANEL.danger : PANEL.warn;
  const cy = Math.round(sy) - 11;
  ctx.fillRect(Math.round(sx) - 3, cy + 2, 7, 1);
  ctx.fillRect(Math.round(sx) - 2, cy + 1, 5, 1);
  ctx.fillRect(Math.round(sx) - 1, cy, 3, 1);
  ctx.restore();
}

export function drawRound(ctx, r, sx, sy, tick) {
  const art = ROUND_ART[r.kind] || ROUND_ART.hammer;
  const x = Math.round(sx);
  const y = Math.round(sy);
  ctx.save();
  if (r.kind === 'bill') {
    // A bullet bill is a shell with a face, drawn nose-first along its track.
    const up = r.vy <= 0;
    ctx.fillStyle = art.rim;
    ctx.fillRect(x - 4, y - 6, 8, 12);
    ctx.fillStyle = art.body;
    ctx.fillRect(x - 3, y - 5, 6, 10);
    ctx.fillStyle = art.rim;
    ctx.fillRect(x - 2, up ? y - 4 : y + 2, 4, 2);
  } else if (r.kind === 'hammer') {
    // A tumbling hammer: the head flips on a four-frame cycle.
    const flip = Math.floor(tick / 4) % 2 === 0;
    ctx.fillStyle = art.rim;
    ctx.fillRect(x - 4, y - 1, 8, 2);
    ctx.fillStyle = art.body;
    if (flip) ctx.fillRect(x - 1, y - 4, 3, 4);
    else ctx.fillRect(x - 1, y, 3, 4);
  } else {
    // Spit and breath: a hot blob with a rim, breathing on a six-frame cycle.
    const grow = (tick % 6) < 3 ? 0 : 1;
    ctx.fillStyle = art.rim;
    ctx.fillRect(x - art.r - grow, y - art.r - grow, (art.r + grow) * 2, (art.r + grow) * 2);
    ctx.fillStyle = art.body;
    ctx.fillRect(x - art.r + 1, y - art.r + 1, art.r * 2 - 2, art.r * 2 - 2);
  }
  ctx.restore();
}

// A gun going off, so the pilot knows a round is his problem BEFORE it is
// close enough to see. This is the pilot's only telegraph and it is
// deliberately small: leading by eye is the Wings of Fury skill (spec 4.2).
export function drawMuzzleFlash(ctx, sx, sy, t, life) {
  const k = 1 - t / life;
  if (k <= 0) return;
  const r = Math.round(3 + 7 * k);
  ctx.save();
  ctx.globalAlpha = k;
  ctx.fillStyle = '#fff0b0';
  ctx.fillRect(Math.round(sx) - 1, Math.round(sy) - r, 2, r);
  ctx.fillStyle = '#ffb03a';
  ctx.fillRect(Math.round(sx) - r / 2, Math.round(sy) - 2, r, 3);
  ctx.restore();
}

// A round connecting. Bigger and whiter than the flash, because taking a hit
// has to be unmistakable at a glance — the panel says how bad, this says THAT.
export function drawHitSpark(ctx, sx, sy, t, life) {
  const k = 1 - t / life;
  if (k <= 0) return;
  const r = Math.round(4 + 14 * (1 - k));
  ctx.save();
  ctx.globalAlpha = k;
  ctx.strokeStyle = '#fff4d0';
  ctx.lineWidth = 2;
  ctx.strokeRect(Math.round(sx) - r, Math.round(sy) - r, r * 2, r * 2);
  ctx.fillStyle = LAND ? '#ff7a2a' : '#ff7a2a';
  ctx.fillRect(Math.round(sx) - 3, Math.round(sy) - 3, 6, 6);
  ctx.restore();
}

export default { drawEmplacement, drawRound, drawMuzzleFlash, drawHitSpark };
```

## Task 4: Naval flak

Spec §5's fourth layer: *"Neutral AA emplacements on some islands — obstacles both players must respect."*

The census is the reason this is in the plan rather than deferred. World 1 — the first archipelago either player ever sees — fields **0, 6, 0 and 1** derived guns across its four islands. Two of them are free bombing ranges. A threat system whose first world has no threat in it has not shipped.

So naval flak is placed **to a floor**: every island fields at least `NAVAL.FLOOR` guns, and an island already bristling gets none. That fixes the hole without flattening the difficulty curve above it — 8-3 keeps its fourteen and gains nothing.

That sounds oppressive and is not, because of what it gives up:

- **A shell is slow to arrive.** At 3.8 px/frame a shot at a plane 500px up is in the air for over two seconds. The lead is computed at launch and never corrected, so **one heading change after the flash makes it a miss.** High altitude is *contested*, not *denied*.
- **There are at most four of them, and only on islands that needed them.** An island with real defences never gets a shore battery, so the pilot is never fighting fourteen hammer bros and four flak guns at once.
- **One point of damage**, like everything except Bowser.

The shape it produces is the one this whole plan is for: **there is no altitude at which bombing is free.** Low is lethal and precise; high is survivable and inaccurate; and the way out of both is suppression, which requires going low *once*, deliberately, with a plan. That is the sortie the pilot should be flying.

```js
export const NAVAL = {
  // Every island fields at least this many guns. The census that motivated the
  // number: world 1 ships 0, 6, 0 and 1 derived emplacements across its four
  // islands, so half of the first archipelago either player ever sees is a
  // free bombing range without this rule. An island that already meets the
  // floor gets nothing, so the curve above it — 8-3's fourteen — is untouched.
  FLOOR: 4,
  // Never within this many columns of either shore. A gun on the beach is
  // a gun the pilot can kill from over open water without ever entering the
  // island's own envelope, which is not an obstacle, it is a formality.
  MARGIN_TILES: 8,
  // Attempts per band before falling back to a linear scan.
  TRIES: 12,
};

// The first tile in a column you could stand on — solid or one-way platform,
// the same predicate Island#blocksTile uses.
//
// Reads `island.rows` DIRECTLY and not `island.charAt`, which is the whole
// point of this function existing rather than being three lines inline:
// charAt returns '.' for a destroyed tile, so a cratered column would report a
// lower surface and the gun standing on it would appear to have MOVED. Worse,
// the count is derived from the level too, so a crater could conjure a gun
// somewhere else on the island. Placement is a property of the level; damage
// is a property of the match; they must not be allowed to mix.
export function surfaceRow(island, tx) {
  if (tx < 0 || tx >= island.w) return null;
  for (let ty = 0; ty < island.h; ty++) {
    const ch = island.rows[ty][tx];
    if (!(ch in CHAR_TO_TILE)) continue;
    const rec = tileForChar(ch);
    if (rec.solid || rec.platform) return ty;
  }
  return null;
}

// A per-island stream off the match seed, so two islands in one archipelago
// do not get the same beach and two matches do not get the same island.
export function navalSeed(seed, islandId) {
  let h = (seed >>> 0) ^ 0x517cc1b7;
  for (let i = 0; i < islandId.length; i++) {
    h = Math.imul(h ^ islandId.charCodeAt(i), 0x01000193) >>> 0;
  }
  return h || 0x2545f491;
}

// Bring the island up to the floor. Deterministic in the level and the match
// seed and NOTHING else — in particular not in `island.destroyed`, which is
// asserted in the tests, because a placement that moved when the pilot bombed
// would be a gun that respawns.
export function navalEmplacements(island, seed) {
  const want = NAVAL.FLOOR - derivedEmplacements(island).length;
  if (want <= 0) return [];
  const lo = NAVAL.MARGIN_TILES;
  const hi = island.w - NAVAL.MARGIN_TILES;
  if (hi - lo < want) return [];

  // Occupied columns: the island's own guns, plus whatever this loop places.
  const taken = new Set(derivedEmplacements(island).map((e) => e.tx));
  const rng = new Rng(navalSeed(seed, island.id));
  const out = [];
  const usable = (tx) => tx >= lo && tx < hi && !taken.has(tx) && surfaceRow(island, tx) != null;

  // One gun per band, so the four of them are spread down the island rather
  // than clustered wherever the first four draws happened to land.
  const band = (hi - lo) / want;
  for (let i = 0; i < want; i++) {
    const b0 = Math.floor(lo + i * band);
    const b1 = Math.max(b0 + 1, Math.floor(lo + (i + 1) * band));
    let tx = -1;
    for (let n = 0; n < NAVAL.TRIES && tx < 0; n++) {
      const c = rng.int(b0, b1 - 1);
      if (usable(c)) tx = c;
    }
    if (tx < 0) {
      // 1-3 is forty columns of open sky out of a hundred and sixty-five, so
      // "the band was all pit" is a real case and not a defensive flourish.
      // Scan outward across the whole island rather than dropping the gun:
      // the floor is the point of this function.
      for (let c = b0; c < hi && tx < 0; c++) if (usable(c)) tx = c;
      for (let c = b0 - 1; c >= lo && tx < 0; c--) if (usable(c)) tx = c;
    }
    if (tx < 0) continue; // an island with no ground at all. There is none.
    taken.add(tx);
    out.push(emplacementAt(island, EMPLACEMENT.FLAK, tx, surfaceRow(island, tx)));
  }
  return out;
}

export function allEmplacements(island, seed) {
  const out = [...derivedEmplacements(island), ...navalEmplacements(island, seed)];
  out.sort((a, b) => (a.id < b.id ? -1 : a.id > b.id ? 1 : 0));
  return out;
}
```

### Why the fireballs bypass `Interp` and are dead-reckoned instead

`Interp` blends two snapshots field by field, and `lerpState` only interpolates keys that are numbers **in both** snapshots. An array of fireballs is not a number, so it would be copied verbatim from the newer sample — which means every fireball on the pilot's screen would teleport in 3-tick steps while Mario himself glides. Worse, `Interp` deliberately runs `INTERP_DELAY_TICKS = 6` behind, and a hit resolved against a 6-tick-stale fireball is a hit resolved against a fireball that is 18 pixels from where Mario threw it.

So fireballs take the other route: **refresh on arrival, integrate forward at 60Hz in between.** `SNAPSHOT_INTERVAL_TICKS = 3`, so a track is never dead-reckoned for more than three ticks, over which a fireball at 3 px/frame moves nine pixels along a path whose gravity we know exactly. That is well inside the fireball's own 6px radius.

Mario's *body* keeps using `Interp` — it already does, `this.remote` is built from it, and a body that stutters is far worse than a body that is six ticks old.

### The intended risk/reward

Mario's counterplay must be **earned**, and every number here exists to keep it that way.

- **A fireball needs a fire flower** and reaches perhaps three tiles above the ground on a bounce. A plane at bombing height (world y ≈ 280, which is 230px above a row-12 surface) is simply out of reach. The fireball threatens the pilot who came down to strafe, and nothing else.
- **A star is the strongest thing in the game and it should feel like it**: Task 6 makes star contact an instant kill, the same way `world._blastKill` already makes star Mario immune to a bomb (see `MODS.md`). Symmetry, not generosity.
- **A bounce strike needs Mario to be rising**, which means he jumped *at* the aeroplane and timed it. Falling into the plane, or standing under it, does nothing. A hit that a player did not aim is not agency.

```js
import { ISLAND_TOP_Y } from './geo.js';

// MARIO FIGHTING BACK, as seen from the cockpit.
//
// Spec 7.3: "Mario's fireball hits the plane? The pilot's client decides."
// So Mario sends facts about himself — where his fireballs are, whether he is
// starred — and this module turns them into world-space hazards the pilot's
// simulation can test its own hitbox against. Nothing in here decides
// anything; Task 6's WingsSim does that. This is reconstruction only.
//
// COORDINATES. Mario's snapshot is island-LOCAL, because that is the frame his
// engine and his camera live in. Everything this module hands out is WORLD
// pixels. The conversion is `originX + x` and `ISLAND_TOP_Y + y`, and it
// happens in exactly one place: ingest().
//
// WHY NOT Interp. lerpState only blends keys that are numbers in both
// snapshots, so an array of fireballs would be copied verbatim from the newer
// sample and would teleport in three-tick steps; and Interp deliberately runs
// INTERP_DELAY_TICKS (6) behind, which is eighteen pixels of fireball. Mario's
// BODY still uses Interp — a body that stutters is worse than a body that is
// six ticks old — but his ordnance is refreshed on arrival and integrated
// forward at 60Hz in between, which is never more than
// SNAPSHOT_INTERVAL_TICKS (3) ticks of extrapolation.

export const COUNTER = {
  // A copy of PHYS.fireballGravity from src/game/physics.js. Copied rather
  // than imported so that this module stays a pure src/wings module with no
  // engine dependency; pinned against the real one in the unit test, which is
  // the only honest way to hold a copy.
  FB_GRAVITY: 0.28125,
  // A fireball is 8px of art; six is generous enough that a near miss at the
  // edge of a three-tick extrapolation still reads as a hit to the player who
  // threw it.
  FB_RADIUS: 6,
  // How many ticks a track survives without being refreshed. Two snapshot
  // intervals plus a margin: a peer that goes quiet must not leave fireballs
  // hanging in the sky for the rest of the match.
  FB_STALE_TICKS: 12,
  FB_MAX: 4,
  // Rising at least this fast (remember +Y is DOWN) to count as a strike
  // rather than a brush. Task 6 reads this.
  BOUNCE_VY: -1.0,
};

// Mirrors HITBOX and POWER in src/game/player.js, for the same reason and with
// the same pinning test.
export const MARIO_BOX = { W: 12, SMALL_H: 16, BIG_H: 32, SMALL_POWER: 'small' };

// The engine's own star predicate (isStarPlayer in src/game/entities/index.js),
// spelled out here so that src/net/mario-side.js — which talks to the game
// ONLY through window.__GAME — does not have to import an engine module to
// answer a question about the player it is already reading.
export function isStarred(p) {
  return !!p && (p.invincible === true || (p.starFrames | 0) > 0 || (p.star | 0) > 0);
}

// Two decimal places is a hundredth of a pixel per frame, which is six
// hundredths of a pixel over the longest dead-reckoning window there is.
export function round2(v) {
  return Math.round(v * 100) / 100;
}

function validRow(row) {
  return Array.isArray(row) && row.length >= 5
    && row.every((v) => typeof v === 'number' && Number.isFinite(v));
}

export class Counterfire {
  constructor() {
    this.tracks = new Map(); // id -> {id, x, y, vx, vy, age}
    this.tick = 0;
  }

  // One Mario snapshot, straight off the wire. `originX` is where the pilot's
  // ocean puts the island the snapshot claims to be from, or null if this
  // pilot has not laid that island out — in which case there is no world
  // position and we do not invent one.
  //
  // The snapshot's list is AUTHORITATIVE and complete: an id that is not in it
  // has stopped existing, because he is the truth about himself (spec 7.1).
  ingest(s, originX, tick) {
    this.tick = tick;
    if (!s || originX == null) {
      this.tracks.clear();
      return this.tracks;
    }
    const rows = Array.isArray(s.fb) ? s.fb : [];
    const seen = new Set();
    for (const row of rows) {
      if (seen.size >= COUNTER.FB_MAX) break;
      if (!validRow(row)) continue;
      const [id, lx, ly, vx, vy] = row;
      seen.add(id);
      this.tracks.set(id, {
        id,
        x: originX + lx,
        y: ISLAND_TOP_Y + ly,
        vx,
        vy,
        age: 0,
      });
    }
    for (const id of [...this.tracks.keys()]) if (!seen.has(id)) this.tracks.delete(id);
    return this.tracks;
  }

  // One fixed step of dead reckoning, on the pilot's clock. Same integrator
  // shape as everything else in this codebase: gravity, then motion.
  step() {
    for (const t of this.tracks.values()) {
      t.vy += COUNTER.FB_GRAVITY;
      t.x += t.vx;
      t.y += t.vy;
      t.age++;
    }
    for (const [id, t] of [...this.tracks]) {
      if (t.age > COUNTER.FB_STALE_TICKS) this.tracks.delete(id);
    }
    return this;
  }

  // What the sim tests against and the scene draws. A copy, so neither can
  // stir the tracker.
  hazards() {
    const out = [];
    for (const t of this.tracks.values()) {
      out.push({ id: t.id, kind: 'fireball', x: t.x, y: t.y, r: COUNTER.FB_RADIUS });
    }
    return out;
  }

  clear() {
    this.tracks.clear();
    return this;
  }
}

export default Counterfire;
```

```js
  // whether one hit the aeroplane is decided on the pilot's machine

  //
```

## Task 6: Mario's strike lands

The last hit. The pilot's client tests the plane's box against Mario's fireballs and against Mario himself, and the plan's balance table gets written down where the next person to tune it will find it.

**Files:**
- Modify: `src/wings/counterfire.js`
- Modify: `src/wings/sim.js`
- Modify: `src/net/pilot-side.js`
- Modify: `tests/unit/counterfire.test.js`

**Interfaces produced:**
- `counterfire.js` — `STRIKE`, `boxesOverlap(a, b, pad)`, `marioBoxWorld(m)`, `fireballHits(h, plane)`, `marioStrike(m, plane)`
- `sim.js` — on `WingsSim`: `setThreats(bundle)`, `stepCounterfire()`, `threats`; `state()` gains `marioFire`
- `pilot-side.js` — `pump()` pushes the threat bundle into the sim

### The intended risk/reward

This is the layer that is easiest to get wrong in either direction, so the three verdicts are argued individually.

| Contact | Verdict | Why |
|---|---|---|
| **Fireball** | 1 point | It costs a fire flower and it reaches perhaps three tiles above the ground. The pilot who took it was strafing. One point makes that a real cost and leaves him able to climb out. |
| **Bounce strike** (Mario rising into the plane) | 1 point | It costs nothing but a jump — but it costs a jump *timed at a moving aeroplane on a low pass*, which is the hardest thing Mario can be asked to do in this game. Rewarding it with less than a fireball would be wrong; rewarding it with a kill would make a low pass unplayable. |
| **Star contact** | **kill** | A star already makes Mario immune to a bomb of any power — `world._blastKill` checks `isStarPlayer` and `MODS.md` records the reasoning at length. Immunity in one direction and one point of chip damage in the other is not symmetry. A star is fifteen seconds long, it is the strongest thing in the game, and it should end an aeroplane that flew into it. |

Two guards keep the model from collapsing into chip damage:

- **A fireball is spent on impact.** Its id goes into a spent set, so one fireball is one point however many ticks it overlaps for. Mario is capped at two fireballs at a time by the engine, so his throughput is bounded by his own throwing.
- **Mario's body has a strike cooldown.** Without it, a starred Mario riding along under the plane, or a big Mario stuck against it, would deal damage every tick — sixty points a second. `STRIKE.COOLDOWN` makes one contact one strike.

And the thing that keeps all of it *earned*: **a falling Mario does nothing, and a standing Mario does nothing.** `vy <= COUNTER.BOUNCE_VY` means he was going *up*. Flying into a Mario who happened to be there is not something Mario did.

```js
// What a contact with Mario himself costs. KILL is INTEGRITY.MAX-or-more
// expressed without importing sim.js (which imports this file's neighbours and
// would make a cycle): any damage at or above the largest airframe is a kill,
// and 99 says that louder than 3 does.
export const STRIKE = {
  KILL: 99,
  // One contact is one strike. Without this, a starred Mario riding along
  // under the aeroplane deals sixty points a second, and a big Mario wedged
  // against it does the same — which turns a duel into a grinder.
  COOLDOWN: 45,
};

export function boxesOverlap(a, b, pad = 0) {
  return a.x < b.x + b.w + pad
    && a.x + a.w + pad > b.x
    && a.y < b.y + b.h + pad
    && a.y + a.h + pad > b.y;
}

// x,y is the plane's TOP-LEFT (ARCHITECTURE.md section 1).
function planeBoxOf(plane) {
  return { x: plane.x, y: plane.y, w: PLANE_W, h: PLANE_H };
}

// Mario's box in WORLD pixels. `m` is already world-space — pilot-side.js
// converts once, in pump(), the same place it converts his body for the radar.
export function marioBoxWorld(m) {
  const h = m.power === MARIO_BOX.SMALL_POWER ? MARIO_BOX.SMALL_H : MARIO_BOX.BIG_H;
  return { x: m.x, y: m.y, w: MARIO_BOX.W, h };
}

export function fireballHits(h, plane) {
  return boxesOverlap({ x: h.x - h.r, y: h.y - h.r, w: h.r * 2, h: h.r * 2 },
    planeBoxOf(plane), 0);
}

// Mario's body against the aeroplane. Returns null for no strike, or
// {kind, damage}.
//
// EARNED, and this is the whole point of the function: a Mario who is merely
// THERE does nothing. He has to be starred — which costs a power-up and lasts
// fifteen seconds — or going UP, which means he jumped at a moving aeroplane
// on a low pass and timed it. Flying into a Mario who happened to be standing
// on a roof is not something Mario did, and the pilot should not pay for it.
export function marioStrike(m, plane) {
  if (!m) return null;
  if (!boxesOverlap(marioBoxWorld(m), planeBoxOf(plane), 0)) return null;
  if (m.star) return { kind: 'star', damage: STRIKE.KILL };
  if ((m.vy || 0) <= COUNTER.BOUNCE_VY) return { kind: 'bounce', damage: 1 };
  return null;
}
```

```js
  // Mario fighting back (spec 5). Runs after stepFlak for the same reason
  // stepFlak runs after checkPlane: an aeroplane already written off this tick
  // must not be written off a second time.
  stepCounterfire() {
    if (this._strikeCool > 0) this._strikeCool--;
    if (this.plane.mode !== MODE.AIR) return;

    for (const h of this.threats.fireballs) {
      if (this._spentFire.has(h.id)) continue;
      if (!fireballHits(h, this.plane)) continue;
      // Spent on impact: one fireball is one point however many ticks it
      // spends overlapping. The engine caps him at two in the air, so his
      // throughput is bounded by his own throwing arm.
      this._spentFire.add(h.id);
      this.emit('marioHit', { kind: 'fireball', x: h.x, y: h.y });
      if (this.takeHit(1, 'mario:fireball')) return;
    }

    if (this._strikeCool > 0) return;
    const strike = marioStrike(this.threats.mario, this.plane);
    if (!strike) return;
    this._strikeCool = STRIKE.COOLDOWN;
    this.emit('marioHit', { kind: strike.kind, x: this.threats.mario.x, y: this.threats.mario.y });
    this.takeHit(strike.damage, `mario:${strike.kind}`);
  }
```

## Deliberately not in this plan

- **Mario seeing the flak.** Nothing on his screen shows a Bullet Bill going up or a shell bursting. This is a consequence of the ruling, not an omission: AA never crosses the wire, so Mario's client has no rounds to draw and, since the rounds are aimed at the plane, could not compute them independently either. It is also *right*: spec §4.2 gives telegraphing to Mario for **bombs**, because a crater is permanent and his only counterplay is not being there. A flak round threatens nothing of his. If it is ever wanted as spectacle, the cheapest honest version is a `flak` array on the **pilot's** 20Hz snapshot, drawn through `mario-overlay.js`'s `hooks` array — that is a self-contained piece of work and it does not change who decides anything.
- **Suppression telegraphing on the pilot's HUD.** The emplacement markers say *where* a gun is; nothing says *which gun just fired at you* or *how long until the next one*. A threat-warning cell would be a genuine improvement and there is no room for one — `CELLS` already spans 3..509 of a 512px panel — so it needs a HUD layout pass, which is its own job.
- **The engine's real enemies ever shooting at the plane.** They do not, they never will under this ruling, and the AA is a parallel system that borrows their identity and their coordinates. A Hammer Bro that Mario stomps keeps being an emplacement on the pilot's screen until the pilot craters the tile. That is a deliberate divergence: the alternative is per-enemy liveness on the wire for four islands at once, which is exactly the traffic spec §4.3 exists to avoid.
- **Sound.** No muzzle report, no shell burst, no hit alarm. The whistle in Plan 4 is on its own Web Audio graph and this would want the same treatment on the pilot's page, which has no audio at all yet. Giving the pilot an audio layer is a plan of its own.
- **The pilot's own gun against Mario.** `ORDNANCE.gun` exists, the tracer is drawn, and whether a machine-gun round hits Mario is **Mario's client's** decision under the existing rule — the exact mirror of this plan. It needs the round positions on the pilot's snapshot and a resolution in `mario-side.js`, and it is not here because this plan is about threats *to* the plane.
- **Torpedoes against the ferry.** Plan 4 built `Ferry#torpedoHits()`; wiring it is that plan's remaining work, not this one's.
- **Anything that changes `Match`.** The win-condition state machine is untouched: everything here funnels into the `lose()` → `planeLost` → `Match#planeLost()` chain that already existed. If a task in this plan appeared to need a change to `src/wings/match.js`, it was the wrong task.
- **Tier-4 two-client integration and tier-5 soak** (spec §8.3) for the counterfire path. Task 5 Step 10 and Task 6 Step 7 are human play-tests, deliberately, because what they are checking — *does this feel earned* — is not assertable.
